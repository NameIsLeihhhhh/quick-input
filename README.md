# QuickInput

按 **Alt+J** 弹一个输入框。打完字回车，有三种去向：

| 你输入的 | 会发生什么 |
|---|---|
| 普通文字 | 进 **DSH 新会话**（不切窗口、不抢焦点） |
| `别名 空格 关键词`（如 `hh 800库`） | 打开浏览器，在该网站搜索 |
| `/关键词`（如 `/季度报告`） | 用 **Everything** 搜本机文件，列表里选中打开 |
| `\` 开头 | 去掉反斜杠，强制当普通文字送进 DSH |

不依赖 Quicker、不联网、不碰剪贴板（默认模式下）。

**可以带附件**：把文件拖到浮层上，或 `Ctrl+V` 贴一张截图 —— 附件跟着正文一起送进 DSH。

---

## 现在就能用

程序**已经在运行**（右下角托盘有图标），**已设开机自启**。

### 用法一：发给 DSH

1. 任何软件里按 **Alt+J**
2. 打字 → **回车**
3. 当前窗口纹丝不动，内容进 DSH 的新会话

浮层左下角会显示去向：

- 绿字 `→ DSH 新会话 · 扩展已连接` —— 会立刻送出去
- 橙字 `⚠ 扩展未连接，内容先排队` —— 浏览器扩展没跑，内容不丢，上线后补发（排队上限 10 分钟）

### 用法二：搜索

1. 按 **Alt+J**
2. 输入 `hh 800库` 或 `hh800库`（**空格可省略**）
3. 回车 → 浏览器打开小红书搜索「800库」

底部提示会实时变紫，**打字时就能看到这一下回车是搜索还是发送**：

- 只打了 `hh` → `→ 小红书 · 空格后输入关键词`
- 打到 `hh 8` → `→ 小红书 搜索 · 回车直接打开浏览器`

| 别名 | 站点 | 别名 | 站点 |
|---|---|---|---|
| `hh` | 小红书 | `db` | 豆瓣 |
| `bb` | B站 | `tb` | 淘宝 |
| `dd` | 抖音 | `bd` | 百度 |
| `gg` | Google | `gh` | GitHub |
| `zh` | 知乎 | `wb` | 微博 |

关键词里的空格会保留：`hh 800库 租房` → 搜「800库 租房」。

### 用法三：搜本机文件

1. 按 **Alt+J**
2. 打 `/` 开头，后面跟文件名（`/季度报告`）
3. 列表里用 **↑↓** 选，回车打开；**Ctrl+Enter** 在资源管理器里定位

走的是 Everything 的内存索引，不是自己遍历磁盘，所以是毫秒级。

- 支持 Everything 的全部语法：`ext:pdf 报告`、`path:工作 季度`、`dm:today`
- **只匹配文件名**。`/季度报告` 找不到「2026 二季度经营分析报告.docx」是因为名字里没有这四个字连在一起 —— 这是 Everything 的默认行为，不是没搜到
- 结果多于一屏时：列表跟着选中项滚，右侧有细滚动条，底部写「第 N / 共 M 条」
- 鼠标：滚轮一格一条，点一下选中，再点一下打开
- **悬停 0.2 秒看全名**：行内放不下的长文件名会被截断，同前缀的几条（同一篇笔记的多个版本）光看行分不出来。鼠标停在某一条上，浮层下方会弹一条详情：**完整文件名 + 完整路径 + 类型 / 大小 / 修改时间**。字号和行内一样大，不缩字，靠换行放下

图标按类型上色（笔记紫、Word 蓝、Excel 绿、PDF 红、图片青、压缩包棕、视频粉、音频橙），文件形和文件夹形是两种轮廓，不用读扩展名。

### 用法四：带文件 / 图片

浮层里可以直接挂附件，和正文一起发出去 —— DSH 那边收到的是一条「正文 + 附件」的消息。

| 怎么给 | 说明 |
|---|---|
| 拖文件到浮层上 | 一次最多 4 个，单个 ≤ 12 MB |
| `Ctrl+V` | 剪贴板里是截图或文件时，贴成附件（不是文字） |
| 点 chip | 移除那个附件 |

- 附件条在输入行下面，显示文件名，点一下移除
- 实测 **27 种类型全部能进**：txt / md / csv / json / xml / html / js / py / cs / log / pdf / docx / xlsx / pptx / zip / svg / mp3 / mp4 / 图片，含中文名、空格括号、110 字符长名、0 字节、2 MB
- 图片会被 DSH 转码后存（库里只有图，没有原文件名），这是 DSH 的行为，不是丢文件
- 需要浏览器扩展 **v5**（`/health` 里的 `client` 字段；低于 v5 附件会被忽略）

### 按键

| 按键 | 作用 |
|---|---|
| `Enter` | 执行（发送 / 搜索 / 打开文件） |
| `Ctrl+Enter` | 文件模式：在资源管理器里定位该文件 |
| `↑` `↓` | 文件模式：在结果里选 |
| `Shift+Enter` | 换行 |
| `Esc` | 收起（不丢内容，见下） |

### 收起和再打开

- **点浮层外面的任何地方，它就自己收起。** 不用先按 Esc。
- **收起不丢内容。** 再按 `Alt+J`，还是刚才那一屏——输入的文字、搜索结果、选中到第几条、滚到哪儿，全都在。全选着，直接打字就覆盖。
- 只有两种情况会真的清空：**回车执行了**，或者你自己把字删光。

## 配置：`qui.ini`

和 exe 放同一目录，托盘右键 → **打开配置文件** 可直接编辑。

### 基本项

```ini
Hotkey=Alt+J
Mode=new
```

- **Hotkey**：支持 `Alt+J`、`Ctrl+Alt+J`、`Win+Space`、`Shift+Alt+K`、`F9`。改完重启生效。
- **Mode**：`new` = 送 DSH 新会话（默认）；`current` = 追加到正在看的会话；`clipboard` = 老办法，粘贴到当前窗口。

### 搜索别名

```ini
[search]
hh = 小红书 | https://www.xiaohongshu.com/search_result?keyword={q}
```

格式：`别名 = 显示名 | 网址模板`。`{q}` 会被替换成搜索词（自动做 URL 编码，中文没问题）。
显示名可以省略；模板里必须有 `{q}`，没有的行会被忽略。

加一个站点只要加一行。比如加个「得到」：

```ini
dd = 得到 | https://www.dedao.cn/search?keyword={q}
```

## 为什么用 Alt+J 而不是 Alt+F

为什么不是 Alt+F：它在 Windows 里是「文件菜单」的通用入口——Chrome、记事本、资源管理器、Office、WPS 全都在用。全局热键一旦注册就独占，等于**把这些软件的文件菜单全部废掉**。

Alt+J 在主流软件里基本没有绑定，冲突面小得多。代价：如果哪个软件确实把 Alt+J 当快捷键用，那个功能会被抢走。

**换热键**：改 `qui.ini` 里的 `Hotkey=`，重启程序。托盘图标右键菜单里会实时显示当前热键。

### 托盘图标

紫色圆角方块 + 白色 Q，和浮层左上角的标记同一套视觉。图标是**内嵌的多尺寸 ico**（16/20/24/32/40/48/64/128/256 共 9 档），Windows 按托盘的实际 DPI 挑最合适的那一档，200% 缩放下取 32px 那版，不会糊。
样式预览见同目录 `icon-preview.png`。exe 文件本身的图标也是它（在资源管理器里看得到）。

## 已知限制（设计取舍，不是 bug）

1. **搜索别名会“抢首词”**。因为支持省略空格（`hh800库`），任何以别名开头的文字都会被当搜索——`bb机` 会去 B 站搜「机」。真要发原话，行首加 `\`。
2. **`clipboard` 模式下会覆盖剪贴板**，且要求目标输入框已经有焦点。默认模式不用剪贴板，没这个问题。
3. **管理员权限的窗口**：`clipboard` 模式下受 UIPI 限制，发不进去就让 QuickInput 也以管理员运行。DSH 模式不受影响。
4. **DSH 模式依赖浏览器扩展**。扩展没装/没刷新时内容会排队，不会丢，但送不到。
5. **搜索是交给系统默认浏览器打开的**，不是指定 Chrome。想指定就得改代码。
6. **文件搜索要求 Everything 在跑**。它提供的是内存索引，Everything 退了就搜不到（浮层底部会写「没有匹配」，不会崩）。
7. **文件搜索只匹配文件名**，不搜正文。要搜正文得在 Everything 里开内容索引，那是它的设置，不是这里的。

## 排查

**先跑这个，一条命令覆盖全部：**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\selftest-all.ps1
```

它测 28 项：本地桥、扩展连接、11 个别名的网址解析、只打别名的提示、不该当搜索的输入、
唤起浏览器、送进 DSH、Everything 命中与列表滚动、收起后状态不丢。全过会打印「全部通过」。

> 副作用两条：会弹一个浏览器标签页；会在 DSH 里建一个叫「QuickInput 自测 HH:mm:ss」的会话（可删）。

四个自检接口（只监听 127.0.0.1，可以单独用）：

```powershell
# 桥是否在线、扩展版本、最近一次失败原因
curl http://127.0.0.1:47321/health

# 已载入哪些搜索别名
curl http://127.0.0.1:47321/search

# 这句话会被解析成什么网址（不真的打开）
curl "http://127.0.0.1:47321/search?q=hh%20800%E5%BA%93"

# 真的走一遍「打开浏览器」（只接受能解析成搜索的输入）
curl "http://127.0.0.1:47321/open?q=hh%E6%B5%8B%E8%AF%95"

# 文件搜索：把浮层直接驱动到某个状态（sel 会把选中项推到第 N 条，自检用）
curl "http://127.0.0.1:47321/debugfiles?q=/a&sel=10"

# 收起浮层（等价于点浮层外面），用来验「再呼出还是上次那屏」
curl "http://127.0.0.1:47321/hide"

# 只唤出、不改内容
curl "http://127.0.0.1:47321/debugfiles"
```

日志：`%TEMP%\quickinput.log`。每次发送都会写一行 `DoSend -> bridge` 或 `DoSend -> search`。

## 开机自启

**已经设好了。** 快捷方式在：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\QuickInput.lnk
```

指向本目录的 `QuickInput.exe`。开机登录后自动起，托盘里就有图标，`Alt+J` 随时可用。

想确认它在不在：`Win+R` → `shell:startup`，应该能看到 `QuickInput.lnk`。
关掉：删掉那个快捷方式，或在「任务管理器 → 启动应用」里禁用。

右键托盘图标 → **退出**。

## 文件说明

| 文件 | 用途 |
|---|---|
| `QuickInput.exe` | 主程序（图标已内嵌） |
| `qui.ini` | 配置（热键、模式、搜索别名） |
| `QuickInput.cs` | 源码 |
| `QuickInput.ico` | 托盘/exe 图标源文件（9 个尺寸），编译时打进 exe |
| `Everything64.dll` | Everything 的 SDK，给文件搜索用（跟 exe 放一起就行，仓库里不带） |
| `build.ps1` | 改完源码后重新编译 |
| `selftest-all.ps1` | **全链路自测，31 项，一条命令跑完** |
| `extension/` | Chrome 扩展（本地桥的另一半）。`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选这个目录 |
| `publish.ps1` | 维护者用：把可发布的文件同步到仓库目录并提交 |

重新编译：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

用的是 Windows 自带的 .NET Framework 编译器，不用装任何东西。`build.ps1` 里带 `QuickInput.ico` 的 `resource` 和 `win32icon` 两个参数，别删——删了托盘图标会退回系统默认那个白纸图标。

> 改过扩展代码后，需要到 `chrome://extensions` 点一次刷新图标才会生效——浏览器不会自动重载扩展。
